# Diseñador de tarjeta NFC

Aplicación web para diseñar el sticker de una tarjeta NFC tamaño carnet (CR80, 85.6 × 54 mm).

- Sube una foto, muévela, haz zoom, agrega texto y color de fondo.
- Descarga una tarjeta en **PDF a tamaño real** o **PNG a 300 DPI**.
- Genera una **hoja A4 de stickers** con la mayor cantidad de tarjetas posible (combina tarjetas normales y giradas), con margen, separación, sangrado y línea de corte configurables.

Las imágenes se procesan en el navegador; nada se sube a internet.

**Al imprimir:** papel A4, escala 100% / tamaño real (no "Ajustar a página").
